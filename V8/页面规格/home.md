# 主工作区（首页）页面规格

> Phase 2 · RFC 关联：RFC-02 §4 + RFC-01 §3.3 + RFC-03 §1
> 唯一真相源：本文为 Phase 2 实现依据，Phase 0 验收清单之 V8 页面规格

---

## 1. 数据加载

| 数据块 | Rust command | 触发时机 |
|---|---|---|
| 今日时间 | `app::local_time()` | 应用启动 + 每分钟刷新 |
| 进行中项目 | `list_projects({status: 'IN_PROGRESS'})` | 首页挂载 |
| 今日待办（未完成） | `list_todos({status: 'PENDING'})` + 客户端按 `due_date` 过滤今日 | 首页挂载 |
| 今日完成 | `list_todos({status: 'COMPLETED'})` + 客户端按 `completed_at` 本地日期过滤今日 | 首页挂载 |
| 下一工作日计划 | `list_todos({status: 'PENDING'})` + 客户端按 `due_date` = 下一工作日过滤 | 首页挂载 |
| 本周项目进度 | 由 `listProjects` 客户端加权平均计算（RFC-02 §2） | 项目数据变化时 |

## 2. 状态机

```
LOADING → READY
LOADING → ERROR（数据加载失败）
READY → EMPTY（所有数据块都为空）
READY → REFRESHING（用户下拉刷新）
```

## 3. 错误处理

| 错误类型 | UX |
|---|---|
| 数据库连接失败 | 顶部红色 banner + 重试按钮 |
| 单个数据块加载失败 | 该区块显示"加载失败"+ 重试按钮，其他区块正常 |
| 部分数据缺失（如 holidays 表为空） | 显示"未配置"+ 跳转设置链接 |

## 4. 空状态

- 无进行中项目：显示"暂无进行中项目"+ "新建项目"按钮
- 今日无待办：显示"今日清空"+ "新建待办"按钮
- 今日无完成：显示"今日还未完成任何待办"
- 下一工作日无计划：显示"下一工作日无计划"+ "新建待办"快捷

## 5. 边界条件

### RFC-02 §4 关键规则
- **今日完成**按 `completed_at` UTC ISO 8601 的本地日期归档（不是 `due_date`）
- 示例：2026-09-10 创建的待办，今天 2026-08-21 完成 → 今日完成显示，原计划日期不变

### 节假日边界
- 今日 = 节假日：今日待办区域显示"今天是 {节日名}，无需工作"
- 下一工作日 = 跳过节假日找最近工作日（最多查 366 天）

### 系统时区边界（RFC-01 §4.2 + §9）
- 应用默认时区 = 系统时区
- 用户变更系统时区只影响未来展示，不重写历史记录
- UTC ISO 8601 字符串存储不变

## 6. RFC 引用

| 条款 | 要求 |
|---|---|
| RFC-02 §2 | 项目进度 = 叶子任务加权平均（work_days > 0 时权重为 work_days） |
| RFC-02 §4 | 自动顺延仅处理当天到期且尚未完成的 MANUAL/WEEKLY |
| RFC-02 §4 | 首页"今日完成"按 completed_at 本地日期归档 |
| RFC-02 §4 | "下一工作日计划"展示下一工作日到期未完成 + 用户手动计划，需标识来源 |
| RFC-03 §1 | 所有数据通过 Tauri typed command 获取，禁止 WebView 直 SQL |

## 7. Given-When-Then 验收样例

### 验收 #1：今日完成归档
```
Given 创建一条 due_date = 2026-09-10 的待办（未来计划）
And 今天 = 2026-08-21
When 用户点击"完成"
Then 首页"今日完成"立即显示该待办
And 该待办的原计划日期（2026-09-10）不变
```

### 验收 #2：项目进度加权
```
Given 项目有 1 个父任务 + 2 个叶子任务（work_days=2 和 8，进度 50 和 100）
When 用户查看项目进度
Then 项目进度 = (2×50 + 8×100) / (2+8) = 90
And 父任务不单独参与平均
```

### 验收 #3：下一工作日跳过节假日
```
Given 今天 = 2026-08-21（周五）
And 用户有一条 due_date = 2026-08-24（周一）的待办
And 2026-08-24 是法定节假日
When 用户查看"下一工作日计划"
Then 显示 due_date = 2026-08-25（周二）的待办（如果有）
```
