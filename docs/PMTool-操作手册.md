# PMTool 操作手册

<p align="center">跟着做，20 分钟上手</p>

> PMTool 是给实施经理的项目管理工作台：项目、任务、报告、知识、模板都收在一处。
> 下面从「第一次打开」开始，照顺序一步步做，走完这些，你就会用了。每段只讲：**点哪 → 填哪 → 会看到什么**。

---

## 第 1 步 · 打开软件

1. 双击桌面上的 PMTool 图标。
2. 第一次打开会弹窗让你**选一个数据目录**（放你项目数据的地方）——选个方便的位置，点确定。
3. 接着选怎么进入：
   - 想先试试 → 点「**7 天免费试用**」，直接开始用。
   - 已有授权码 → 粘贴进来，点「**激活授权**」。
4. 进到**主工作区**主页。

> 左侧一排是你常用的 8 个页面，点哪个进哪个（主工作区 / 任务中心 / 项目中心 / 报告中心 / 知识中心 / 模板中心 / 设置中心）。

---

## 第 2 步 · 看看今天要干什么（主工作区）

打开进来第一眼就是它。

- **顶部三格**：今天还有几件待完成、已完成几件、右边一个「**生成日报**」按钮（点一下自动生成今天的日报，去报告中心看）。
- **左边日历**：翻月，点某天看那天的待办；法定节假日红字，有当天待办的日期有小圆点。
- **今日待办**：列出今天的事，点前面的**圆点**就是完成；下面输入框可**快速添加**（打字，想关联项目就打「@」选项目，回车）。
- **右下今日工作内容**：一行一行记今天干了啥；**待办完成会自动加一行**。
- **左下下个工作日计划**：提前看明天要做什么（自动跳过周末节假日）。

**先这样用就行**：每天打开，看一眼还剩几件，做完点圆点，右下写两句今天做了什么。

---

## 第 3 步 · 建你的第一个项目（项目中心）

1. 切到左侧「**项目中心**」。
2. 点右上「**+ 新建项目**」。
3. 填**项目编号**（比如 `PRJ-2026-010`）和**项目名称**，点确定。
4. 项目出现在列表里。点它 → 进入**项目详情**。

**项目详情最上面 4 个数字**：整体进度、父任务数、子任务状态、项目周期。下面有 6 个页签，第 4、5、6 步会用到。

---

## 第 4 步 · 在项目里加任务（计划管理）

点项目详情里的「**计划管理**」页签：

- **项目概况**：直接改项目信息（状态、客户、负责人、合同金额、背景、目标、范围），改完自动保存。
- **任务计划**：看计划树。
  - 想加大阶段（比如「需求调研」「系统实施」）→ 点右上「新增」那类入口，填名称。
  - 在大阶段里加子任务 → 点阶段行的「**新增子任务**」，填名称、开始/结束日期、负责人、完成度。
  - 想改哪一行，直接在格子里点一下就能改，改完自动保存。
- **甘特图**：看整个时间线。颜色区分状态（灰=没开始 / 橙=做到一半 / 绿=完成 / 红=延期）。
- 上面工具栏可**下载模板 / 导出 Excel / 导入 Excel**（导入时选**追加**还是**覆盖**）。

**每天进项目就做**：看看哪个任务该做了、哪个延期了，把它改到进行中、填上完成度。

---

## 第 5 步 · 写每周工作、填登记册

- 「**每周工作情况及下周任务**」页签：按周填本周做了什么、下周计划。点「新增周记录」，表格里直接改（改完自动保存）；「结转」把下周没做完的挪到下下周。
- 「**登记册**」页签：四张表——**风险 / 需求 / 问题 / 待办**。
  - 点空白行直接填内容，填完离开格子就保存。
  - 问题登记册经常填：问题、谁提的、涉及哪个模块、处理人、计划解决时间、状态。
  - 每张表都能**导入 / 导出 Excel**（把线下表导进来、或导出去给客户）。

**客户/经理爱看的就是这四张表**，每周往里填，比临时攒数据省事。

---

## 第 6 步 · 生成第一份报告（报告中心）

1. 切到「**报告中心**」。
2. 右上选**日 / 周 / 月报**，选**范围**（个人 或 某个项目）。
3. 点「**生成**」→ 报告自动填好当前周期数据。
4. 列表里点「**查看**」看内容；要改点「编辑」；「复制」拷走。
5. 上面一条时间轴：左右箭头挑早几周/早几月；点「今天」回到当前。

> 这个周期已有报告，再点「生成」会让你确认覆盖。

---

## 第 7 步 · 把常看的资料存进知识中心

- 「**知识中心**」→「**个人知识中心**」：
  - 左边建目录（可建多级文件夹），右边写笔记。
  - 笔记用**富文本或 Markdown**写，可打标签、加分类；右上可放大全屏写。
- 项目相关的 →「**项目知识中心**」：把知识库关联到某个项目，写这个项目的资料。
- 顶部**搜索框**：直接搜全库所有笔记。

**把周报模板、评审清单、客户会议纪要放进来**，下次直接搜。

---

## 第 8 步 · 看看设置（设置中心）

- **个人**：姓名、邮箱、角色；**机器码**（复制给管理员用来生成授权）。
- **外观**：主题（浅/深/跟随系统）、主色、字号。
- **数据**：数据目录在哪、**自动备份**开关 + 备份时间；备份列表里可还原、删除。
- **自动化**：任务自动顺延（没做完自动挪日子）、报告自动生成（几点生成）、启动提醒。
- **法定节假日**：选来源、点「立即同步」，软件就知道哪天放假。
- **授权**：看还剩几天试用；把管理员给的授权码粘贴进来激活。
- **关于**：版本、授权状态。

---

## 这几步走完，你已经会用了

再记三个顺手操作就齐了：

| 想做的事 | 去哪 |
|---|---|
| 我今天还有几件没做 | 主工作区 顶部 |
| 加个待办 | 主工作区 今日待办 下方输入框，或 任务中心 快速收集 |
| 没做完的事挪到明天 | 任务中心 → 「顺延」 |
| 项目卡在哪 | 项目中心 → 点项目 → 登记册 / 计划管理 |
| 给客户写周报 | 报告中心 → 生成周报 → 编辑 |
| 找以前的资料 | 知识中心 → 搜索 |

## 常见问题

| 我遇到… | 怎么办 |
|---|---|
| 授权怎么激活 | 设置中心 → 授权 → 粘贴授权码 → 激活；把机器码发给管理员 |
| 试用快过期 | 联系管理员拿授权码，激活后就是正式版 |
| 待办老自己冒出来 | 是周期任务或周报里带进来的；去任务中心「周期性任务」看 |
| 报告生成的不是最新 | 再点「生成」会覆盖旧的（会提醒你） |
| 数据怕丢 | 设置中心 → 数据 → 开自动备份；或手动「立即备份」 |
| 想换电脑/换地方存 | 设置中心 → 数据 → 迁移目录 |
